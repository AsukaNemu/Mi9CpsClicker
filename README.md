# 米9 连点器

为小米 9（cepheus / Android 11）制作的单点 CPS 连点工具。

## 功能

- 桌面应用入口与参数设置页
- 可拖动的悬浮点击准星
- 1–50 CPS
- 有限次数或无限循环（次数填 `0`）
- 悬浮开始、暂停与关闭
- 无 Root 运行，使用 Android 无障碍手势

## 使用

1. 打开桌面的“米9 连点器”。
2. 开启“米9 连点器点击服务”和悬浮窗权限。
3. 设置 CPS 与次数，点击“保存并启动悬浮控制”。
4. 在目标应用中拖动绿色准星，然后点击“开始点击”。

点击开始后，准星会变为不可触摸状态，手势会落到准星下方的应用。可随时通过悬浮面板暂停。
